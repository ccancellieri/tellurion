# Contributor rights policy

Tellurion 0.5.0-rc.1 is distributed under `AGPL-3.0-only` and may also be offered under
separate commercial terms. The project therefore needs sufficient rights to relicense
every accepted contribution.

Tellurion is an independent project created and owned by Carlo Cancellieri. See the
[copyright notice](COPYRIGHT.md) for the boundary around third-party materials.

No contributor licence agreement or copyright-assignment process is currently in
effect. Opening a pull request does not assign copyright and does not grant Tellurion
additional relicensing rights beyond the licence that otherwise applies.

Until a qualified, recorded contributor agreement has been introduced, external code
and documentation pull requests cannot be merged. Bug reports, reproductions, design
discussion, review comments, and other issue contributions remain welcome. See
[CONTRIBUTING.md](CONTRIBUTING.md).

This temporary boundary avoids pretending that text in a pull-request template is an
executed legal agreement. It can be replaced only after qualified review.
