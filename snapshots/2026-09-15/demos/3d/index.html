Tellurion · live capability

Footprints become streamable 3D.

This browser view connects to a public Tellurion service and renders a representative GLB tile generated on demand from polygon footprints and height attributes. The same service publishes the complete 3D Tiles 1.1 tileset and implicit subtree for streaming clients.

Pipeline

GeoPackage polygons → vector tiles → footprint extrusion → GLB, served by one Tellurion process.

Standard

The payload is 3D Tiles 1.1, an approved OGC Community Standard, including implicit tiling.

Data

Synthetic capability data: 30 deterministic blocks with varied heights, not a model of real buildings.

The URL shape follows Tellurion’s draft-inspired 3D API lane; OGC API 3D GeoVolumes remains a draft, so this page makes no API-conformance claim.
