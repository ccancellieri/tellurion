Evidence discipline

Show what works. State what it proves.

Five active backends

Raster, Zarr and 3D use historical checksum-verified Tellurion 0.3.0 artifacts; vector and Italy harvest build the same pinned public v0.5.0-rc.1 source snapshot.

Standards-aware

3D Tiles 1.1 is identified as an approved OGC Community Standard; draft-inspired API routes are not labelled conformant.

Licence-aware

Demo code, Tellurion software, OpenStreetMap data and ESA WorldCover each retain their own terms and attribution.
