# Contributing to Tellurion

Thank you for your interest in Tellurion. Please read this page before opening
a pull request — it explains what can be accepted and why the bar exists.

## The short version

- **Bug reports, reproductions, and design discussion in issues: always
  welcome**, from anyone, no paperwork.
- **External code and documentation pull requests are not merged yet.** The
  project first needs a qualified, recorded contributor agreement that preserves
  the rights required for dual licensing.

## Why the assignment requirement exists

Tellurion is an independent project created and owned by Carlo Cancellieri. It is open
source under [AGPL-3.0-only](LICENSE) and may also be licensed commercially by Carlo
Cancellieri. That model works only while the licensor holds
sufficient relicensing rights to every line in the repository.

A contribution merged without an additional rights grant would be available
under its inbound licence, but would not give the project permission to offer
that contribution under incompatible proprietary terms. A qualified
contributor agreement is therefore required before accepting external source
or documentation changes into a dual-licensed codebase.

## How to contribute now

Open an issue describing the problem, a minimal reproduction, and the outcome
you need. Please do not invest in a code change with the expectation that it can
already be merged. The project will publish a reviewed contributor process
before accepting external source contributions.

Text-only issue reports, architecture feedback, and review comments are
welcome. Submit only material you have the right to share. If a reproduction
contains copyrightable code or data, its applicable licence still matters.

## Conduct

Be precise, be kind, and argue from evidence. Reproducible tests, documented
constraints, and measurements with their full method outrank opinion here.
