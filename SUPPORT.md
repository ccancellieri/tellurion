# Tellurion support

Tellurion Community is self-hosted open-source software. The repository provides no
Tellurion Cloud service, service-level agreement, response-time commitment, or implied
production support.

Tellurion is an independent project created and owned by Carlo Cancellieri.

For a reproducible defect, open a bug report and include the smallest safe example,
Tellurion version or commit, build features, deployment shape, expected result, and
actual result. Never include credentials, private URLs, customer data, or other
confidential material in a public issue. Report security vulnerabilities through
GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md).

For a self-hosted evaluation, use the evaluation-feedback issue form. It is designed
to identify real deployment and data-format needs without promising that a requested
capability already exists. Community responses are best-effort.

Separate commercial licensing or support terms may be discussed through the
[project author's GitHub profile](https://github.com/ccancellieri). They exist only
when recorded in an executed agreement.
