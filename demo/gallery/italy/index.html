Reproduce before believing

Two commands. Local by default.

  1. Download and unzip the versioned kit.
  2. Run the bundled snapshot without network access.
  3. Optionally refresh OSM and the WorldCover COG window.
  4. Share the exact command, environment and metrics when disagreeing.

SHA-256:
28d84f5d9d1ebbc6333f8054f8ec37d15e061ff2b3eeb79f1d7d70d5b952d98c

shell · local snapshot
unzip tellurion-italy-demo-v0.2.0.zip
cd tellurion-italy-demo
chmod +x reproduce.sh
./reproduce.sh

# Refresh both internet sources
./reproduce.sh --refresh

# Install the current public macOS/Linux binary
./reproduce.sh --install
./reproduce.sh --load-rome
./reproduce.sh --serve-rome

Availability: Tellurion 0.3.0 binaries are public for macOS Apple Silicon, Linux x86_64 and Windows x86_64. The shell installer supports macOS/Linux directly and verifies the selected archive against the release SHA-256 manifest.
